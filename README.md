# Space-Escape-Runner-
🚀 Space Escape — Galaxy Adventure Game

Space Escape is an interactive space-themed game where players control a spaceship and navigate through a dangerous galaxy while avoiding obstacles and trying to survive as long as possible.

The game was developed as a beginner-friendly mobile game project using React Native and Expo, focusing on creating the gameplay experience using simple UI components and game logic.

✨ Features

🚀 Player-controlled spaceship

🌌 Space and galaxy-themed environment

☄️ Obstacles and space objects

🎮 Interactive gameplay

💥 Collision detection

❤️ Player lives / game-over mechanism

🏆 Score-based gameplay

🔄 Restart and replay functionality

📱 Designed for mobile devices

⚡ Smooth real-time movement

🎨 Simple and engaging space-themed interface


🎮 How to Play

1. Launch the game.


2. Control the spaceship using the available controls.


3. Navigate through space and avoid incoming obstacles.


4. Survive for as long as possible.


5. Earn points while progressing through the game.


6. Avoid collisions to keep playing.


7. When the game ends, restart and try to achieve a higher score.



🧠 Game Concept

The main concept of Space Escape is based on survival and obstacle avoidance.

The player controls a spaceship travelling through a galaxy filled with obstacles. The objective is to keep the spaceship safe while progressing through the game and achieving the highest possible score.

🏗️ Game Architecture

The game can be divided into the following major components:

🚀 Player

The player controls the spaceship and moves it through the game environment.

🌌 Game Environment

The game provides a galaxy/space-themed environment in which the spaceship travels.

☄️ Obstacles

Obstacles appear in the player's path and require the player to react and avoid collisions.

💥 Collision Detection

The game checks whether the spaceship comes into contact with an obstacle.

🏆 Score System

The player's score increases as they successfully continue through the game.

🎮 Game Controls

User interactions control the movement of the spaceship and allow the player to navigate through the environment.
